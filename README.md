# Data Science & Machine Learning Portfolio

[![Python Version](https://img.shields.io/badge/Python-3.8%2B-blue.svg)](https://www.python.org/)

Welcome to my Data Science and Machine Learning repository. This portfolio demonstrates practical, end-to-end applications of the data science lifecycle—spanning from automated web scraping and rigorous data preprocessing to predictive machine learning modeling and time series forecasting.

---

## 📂 Repository Architecture

The codebase is organized into modular sections, each focusing on a core domain of data science:

### 🤖 Machine Learning & Predictive Modeling
Implementation of foundational and advanced algorithms to solve complex classification and regression problems.
* **Algorithmic Frameworks:** Linear Regression, Logistic Regression, Decision Trees, Support Vector Machines (SVM), and XGBoost.
* **Benchmark Projects:**
  * `Titanic Survival Prediction` – Binary classification utilizing ensemble methods.
  * `Iris Classification` – Multi-class classification exploring feature boundaries.

### 🧹 Data Preprocessing & Feature Engineering
Robust data cleaning and transformation techniques designed to optimize model performance and prevent data leakage.
* **Feature Scaling:** Normalization and Standardization.
* **Imputation Strategies:** Simple Imputer and Frequency-based value imputation.
* **Categorical Encoding:** One-Hot Encoding and Ordinal Encoding.
* **Pipeline Optimization:** Streamlined workflows integrated via `ColumnTransformer`.

### 📈 Time Series Forecasting
Statistical modeling designed to analyze and predict sequential, time-dependent trends.
* **ARIMA Modeling:** Baseline and optimized Autoregressive Integrated Moving Average (ARIMA) frameworks for tracking historical trends and seasonality.

### 📊 Data Analysis & Visualization
Exploratory Data Analysis (EDA) pipelines built to extract actionable insights from raw data.
* **Exploration:** Automated data profiling and deep-dive Date & Time feature analysis.
* **Extraction:** Programmatic data extraction and structured loading.

### 🕸️ Web Scraping & Data Mining
Custom scripts built to harvest real-world, dynamic data from live web sources.
* **Implementations:** Automated scrapers extracting corporate metrics, including the *Largest Companies in the USA* and *Largest Tech Companies by Revenue*.
